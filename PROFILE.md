# Cracked API

Cracked is a tool router for AI agents: one API key and one prepaid balance to discover, inspect, run and poll thousands of third-party tools. It exposes 9,521 endpoints from 1,183 providers plus 50,000+ Apify actors, publishing measured success rate, median latency and per-call price per tool.

## APIs

- **Cracked API** — REST/HTTP API to discover, inspect, run and poll third-party agent tools, with smart-run capabilities, leaderboards, wallet balance and agent self-registration. Exposes OpenAPI 3.1, two hosted MCP servers (authenticated and no-auth), an llms.txt, and a published agent skill plus A2A agent card. (`https://cracked.ai/v1`)

> All four surface types confirmed on the provider's own site: REST API at https://cracked.ai/v1 (OpenAPI 3.1 at /openapi.json), two hosted MCP servers (/mcp authenticated via OAuth 2.1 or ck_live_ Bearer token, /mcp/public no-auth), an llms.txt (plus llms-full.txt), and an agent skill (SKILL.md v0.7.0). An A2A agent card is published at https://cracked.ai/.well-known/agent-card.json and OAuth metadata at /.well-known/oauth-authorization-server. An apis.json is served at https://cracked.ai/apis.json. No AsyncAPI, GraphQL or public Postman collection found; async handled via HTTP 202 polling on /v1/runs/{id}.
