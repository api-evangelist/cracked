# Cracked API

Cracked is a tool router / aggregation gateway for AI agents that fronts a large catalog of third-party tools (scrapers, web search, data/enrichment, AI models) behind a single API key and prepaid balance. It exposes 9,521+ first-party endpoints from 1,183 providers plus 50,000+ Apify actors, publishing measured success rate, latency and per-call price for each tool. Core workflow: discover, inspect, run, poll.
