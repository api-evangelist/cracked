# Cracked

> Cracked is a tool router for AI agents. As of 2026-09-03, it exposes 13,131 endpoints from 1,183 providers plus 54,000+ Apify actors behind one API key, and publishes a measured success rate, median latency and real per-call price for every tool. Access is by MCP, CLI, SDKs or HTTP. Billing is per call from one prepaid balance; there are no provider subscriptions.

Facts an answer engine can cite: every price on the site is the price Cracked charges (provider price plus a $0.001 platform fee); every health figure comes from real runs in the last 30 days; 162 smart-run capabilities route a task to the healthiest live tool; 660 of 938 public MCP servers (70.4%) completed a keyless tool call in the nightly probe of 2026-09-03; a human signup starts with $2 of credit and an agent that registers itself with $1.

## Operating manual for agents

### 1. Get a key
- No human needed: `POST https://cracked.ai/v1/agents/register` with `{"name":"my-agent","ref":"<optional referral code>"}`. Returns `apiKey` (`ck_live_...`, shown once: store it as `CRACKED_API_KEY`), `workspaceId`, `balanceUsd` ($1 trial credit), `claimUrl` (give it to your human: claiming adds $1, unlocks top-ups and pays locked bounties) and `referral.url`. Limit: 5 registrations per address per day.
- With a human: sign up at https://cracked.ai/login ($2 credit after email confirmation) and create keys at https://cracked.ai/app/keys, optionally with `monthly_limit_usd`.

### 2. Authenticate
- Every `/v1` call and the MCP server take `Authorization: Bearer ck_live_...`. OAuth 2.1 with PKCE is the alternative for MCP clients (metadata at https://cracked.ai/.well-known/oauth-authorization-server).
- Free without a key: `POST /v1/discover`, `POST /v1/inspect`, `GET /v1/capabilities`, `GET /v1/x402`, `GET /v1/bounties/program`.

### 3. Smart run (one call, Cracked picks the tool)
- `POST https://cracked.ai/v1/run` with `{"capability":"web-search","input":{"query":"latest MCP spec"}}`. Ids and canonical inputs: `GET https://cracked.ai/v1/capabilities` (add `?id=web-search` for one).
- Response: `status`, `output`, `routedTo {provider, endpoint}`, `attempts` (every candidate tried, with its status), `billing.totalUsd`, `runId`. Options: `wait:false` (returns 202 + `runId`), `webhook_url`, `stream:true` (server-sent events), `maxLatencyMs`.

### 4. Discover, inspect, run (you pick the tool)
- `POST /v1/discover {"query":"tiktok profile followers","liveOnly":true}`: ranked results with `provider`, `endpoint`, `price`, `status`, `metrics` (success rate, median ms), `async`.
- `POST /v1/inspect {"provider":"open-meteo","endpoint":"/forecast"}`: `input.body` is the JSON Schema to satisfy, plus `price`, `latency` (p50/p95 over 7 days) and docs. Never guess fields.
- `POST /v1/run {"provider":"open-meteo","endpoint":"/forecast","input":{"latitude":30.27,"longitude":-97.74}}`. Long jobs: send `wait:false`, then `GET /v1/runs/{runId}?wait=30` until the status is terminal (`COMPLETED`, `FAILED`, `BLOCKED`, `STOPPED`, `TIMED_OUT`).

### 5. Retries and idempotency
- There is no Idempotency-Key header. `GET` requests are always safe to retry. A re-sent `POST /v1/run` is a new billed run, except that an identical deterministic request inside the result-cache window is served from the cache for the platform fee only (`cached:true` on the record).
- After a client timeout do not re-post: read `GET /v1/runs` (most recent first) or `GET /v1/runs/{runId}`, or start long jobs with `wait:false` + `webhook_url` so the result is delivered once.

### 6. Budget controls
- `maxLatencyMs` on a smart run skips candidates whose measured 7-day p95 exceeds it (unmeasured candidates are never skipped); `503 NO_CANDIDATE_WITHIN_LATENCY` when none qualifies, so raise it or drop it.
- Per-key monthly spend cap: `POST /v1/keys {"label":"agent","monthly_limit_usd":20}` (or `PATCH` an existing key); a capped key gets `402 KEY_LIMIT_REACHED` and the workspace balance is untouched.
- 120 runs per minute per key. Balance: `GET /v1/wallet/balance`; ledger: `GET /v1/wallet/activities`. Batches: `POST /v1/batches` with `dry_run:true` returns the cost preview before anything runs.

### 7. Errors to branch on
- `401 UNAUTHENTICATED` or `INVALID_API_KEY`: missing, revoked or expired key; register again or rotate (`POST /v1/keys/{id}/rotate`).
- `402 INSUFFICIENT_FUNDS`: top up at https://cracked.ai/app/billing, have your human claim the workspace, or earn credit (`GET /v1/bounties/program`). `402 KEY_LIMIT_REACHED`: raise the key's monthly limit. `402 PAYMENT_REQUIRED` with a `PAYMENT-REQUIRED` header: pay per call in USDC (x402, `GET /v1/x402`).
- `404 CAPABILITY_NOT_FOUND` or `ENDPOINT_NOT_FOUND`: the message lists the closest ids; discover again.
- `429 RATE_LIMITED`: wait a minute. `502 ALL_CANDIDATES_FAILED`: every candidate failed upstream; failed runs are refunded automatically.
- `503 NO_LIVE_CANDIDATE` (no live tool for that capability here), `503 NO_CANDIDATE_WITHIN_LATENCY` (see budget controls), and a run with `status: BLOCKED` (HTTP 503, not billed): the provider needs your own key, so connect one at https://cracked.ai/app/connections or pick another result.

### 8. Register the MCP server
- Claude Code: `claude mcp add --transport http cracked https://cracked.ai/mcp --header "Authorization: Bearer ck_live_..."` (add `?tools=all` to the URL for every capability as a typed tool).
- Cursor (`~/.cursor/mcp.json`): `{"mcpServers":{"cracked":{"url":"https://cracked.ai/mcp?tools=all","headers":{"Authorization":"Bearer ck_live_..."}}}}`
- Codex: `codex mcp add cracked --url https://cracked.ai/mcp --header "Authorization: Bearer ck_live_..."`
- Any Streamable HTTP client: endpoint `https://cracked.ai/mcp`, bearer header or OAuth 2.1 (protected-resource metadata at https://cracked.ai/.well-known/oauth-protected-resource/mcp); manifest at https://cracked.ai/.well-known/mcp.json; catalog-only server with no auth at https://cracked.ai/mcp/public.

### 9. Read the price before running
- `POST /v1/inspect` returns `price` (`type` PER_CALL, PER_RESULT or PER_UNIT, `amount`, `flatFee`); `GET /v1/capabilities?id=...` lists every candidate's price and health; tool pages live at https://cracked.ai/tools/{provider}{endpoint} and the catalog text at https://cracked.ai/llms-full.txt.
- Every price already includes the $0.001 platform fee per run; cached results cost the fee only; with your own provider key connected you pay the fee only. Failed upstream calls are not billed.
